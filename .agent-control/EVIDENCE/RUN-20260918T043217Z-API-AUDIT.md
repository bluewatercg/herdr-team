## Current source trace

### Persistence and identities

`DheaStore` persists subject hash, bundle, unique `analysis_id`, image and metadata hashes, immutable object IDs, frozen profile ID/SHA, state, final response, and result object. `DheaService.accept()` verifies an existing bundle against image and metadata hashes, returns every non-failed stored result without Core execution, and only allows a failed record to retry when the currently loaded profile ID/SHA matches the stored profile. A retry retains `analysis_id`, bundle, image object, and result identity while receiving a new `execution_id`.

Frozen-v2 identity semantics are:

- `capture_bundle_id`: public immutable capture, idempotency, and public lookup identity.
- `analysis_id`: Gateway-created and persisted accepted-analysis identity.
- diagnostic `request_id`: exactly the persisted `analysis_id`; no unrelated public request ID is added.
- `execution_id`: one actual Core execution; final replay and GET do not create one.

Current deficiency: these semantics are not a required Core input. `Diagnostics(...)` receives them, but collector construction is optional and failure sets `collector=None`. The Core call then receives only frozen JPEG bytes and expected SHA. Output profile/source checks occur in Gateway after execution.

### Core science path

`DheaRuntime._analyze()` verifies byte type/size and SHA before JPEG decode; accepts only complete JPEG scan data; reads EXIF orientation; normalizes to upright; localizes the observation window; resolves physical direction independently of App labels; rectifies to 256x24 canonical left-to-right flow; extracts Green; records raw profile, rolling-median baseline and signal; measures T and C; refuses invalid C before T/C; preserves valid T/C if guarded 4PL inversion refuses; and returns research-only markers with `formal_reporting_allowed=false`.

The selected direction evidence records original/upright flow origin and far end, canonical flow, and the rectified canvas. Search topology remains flow-origin -> T -> blank -> C -> far-end.

### Diagnostics and result isolation

Gateway commits the result before publishing diagnostics. Diagnostic publication failure cannot rewrite the committed result. Stages/artifacts bind bundle, analysis/request ID, execution ID, original and metadata SHA, research profile ID/SHA, and source versions. Downloads re-hash private bytes and fail closed on missing or mismatched data.

The present Web routes are bundle-addressed:

- `GET /api/v2/lfa/measurements`
- `GET /api/v2/lfa/measurements/{capture_bundle_id}/stages`
- `GET /api/v2/lfa/measurements/{capture_bundle_id}/artifacts`
- `GET /api/v2/lfa/measurements/{capture_bundle_id}/artifacts/{artifact_id}`

History items include `analysis_id`, but the list accepts only `limit`, `offset`, `device_model`, `device_instance_id`, `bundle`, and `status`. The workbench offers no supplied-request-ID control. A12 is therefore not currently executable from `request_id`.
