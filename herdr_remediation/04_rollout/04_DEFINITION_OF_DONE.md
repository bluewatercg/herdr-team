# Definition of Done

整改完成必须同时满足：

- Delivery Profile 可配置、版本化、确认和变更。
- Task 能被校准为 Change Class 与 Risk Flags。
- Effective Policy 确定性生成。
- Acceptance Contract 有 Schema、fixtures、validator。
- Reviewer 与 PM Gate 绑定同 revision。
- Repair 与 Regression 状态机生效。
- BTW 不再触发 Documentation Loop。
- Dashboard 只消费 Projection。
- Run / Task / Evidence 三层页面可用。
- UI 能显示 Declared / Effective、Needs Attention、Gate Chain。
- Legacy 任务安全显示。
- 支持影子运行和回滚。
- 关键测试全部通过并有 evidence refs。
